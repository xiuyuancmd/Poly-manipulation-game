# 《形变工坊 PolyForm》设计文档

> 一个关于"揉捏一团有脾气的软体"的解谜游戏。
> 本文档是完整的设计与实现说明，含关卡剧透。

## 1. 核心概念

玩家在**数分钟时限**内，把一个**柔性、弹性多边形**依次摆成一系列**目标形状**。
多边形内部埋有**管道结构**；目标同时约束**外轮廓**与**管道布局**。

关键设计支柱：

1. **物性未知**：所有管道外观完全相同（中性灰蓝色），但材质各异——
   刚硬、收缩、加压、脆性。玩家只能通过拖拽实验来发现它们的脾气。
2. **不可逆决策**：切割不能撤销。切错了管道，后面的目标可能永远做不出来，
   只能重开本关。时限 + 不可逆构成决策压力。
3. **持续读值**：屏幕常驻 0–100 的实时相似度仪表（外形分/管道分分解），
   玩家的每一次操作都能立刻看到反馈；达标需要**保持**，不是瞬间碰线。

## 2. 操作

| 工具 | 快捷键 | 操作 | 说明 |
|------|--------|------|------|
| 牵拉 | 1 | 按住拖动 | 软手掌抓取（一小片材料随手移动）；**抓取+图钉合计最多 3 个控制点** |
| 钉住 | 双击 | 双击某点 | 图钉将该点固定在原地，再次双击解除 |
| 切割 | 2 | 从**软体外部**按下、划一条线 | 完整穿过→一分为二；止于内部→切出开缝；切到管道→管道断开；切到焊缝→焊缝裂开 |
| 粘合 | 3 | 按住一段边缘，拖到另一段边缘松开 | 两段边界焊接在一起；焊缝日后可被切开 |

3D 关卡：拖拽/双击钉住表面顶点；切割工具**点击**管道剪断；拖动空白处旋转视角。
（v1 的 3D 不支持切割本体与粘合。）

## 3. 物理模型（自研 XPBD）

粒子 + 约束，`dt = 1/60`，8 子步小步长求解（Macklin small-steps 方案），
全局速度阻尼 + 限速防爆。

### 3.1 2D 软体 = 边界环 + 内压 + 弹簧格架

不做 FEM 三角剖分——**环手术**（切割/粘合）在有序索引环上做拓扑操作即可，
无需重网格化：

- **边界环**：粒子按序成环，相邻距离约束（弹性膜，可拉伸 ~10%），
  skip-2 抗弯约束（抑制褶皱）。
- **面积约束（凝胶/气球）**：`目标面积 = 静息面积 × 压力系数`。
  压力系数 = 基础压 + Σ(存活加压管道的贡献)。**切断加压管 → 系数下降 → 整体瘪掉**。
- **格架**：环上跨弦弹簧（步长 1/4、1/2 周长），提供温和的形状记忆。
- **管道** = 体内粒子链。中段用**单向绳索**（只抗拉伸）系在边界上，
  两端**双向刚性锚定**（"肌腱止点"），力量才能传到体壁。

### 3.2 隐藏物性一览（剧透）

| 类型 | 拉伸柔度 | 特性 |
|------|----------|------|
| normal 普通 | 3e-4 | 跟着身体走，无特殊行为 |
| rigid 刚管 | 1e-6 | 硬骨头：撑住跨距，抗弯极强 |
| contractile 收缩 | 3e-5 | 肌腱：链段收缩 + **端到端"弓弦"约束**（防止链条盘绕卸力）；剪断即释放拉力 |
| pressure 加压 | 2e-4 | 闭环 + 面积约束（充气），链长按 √inflate 放大（等周不等式要求，否则约束永远打架）；被切 → 泄气，同时降低**身体**压力系数 |
| brittle 脆管 | 1e-4 | 应变超阈值自断（啪！） |

### 3.3 切割手术

刀刃 = 从体外出发的线段。几何上被刀穿过的一切（格架簧、管道段、焊缝）都被切断。

- **完整二分**：环在两个交点处断开，各自沿切线（带独立的新粒子列）闭合成两个环。
  **静息面积按当前面积比例分配**（材料属性守恒，避免手术吞掉正在发生的泄气）。
- **开缝**：环在入口处"翻折进去"——左右两列复制粒子 + 共享缝尖，环仍是单环。
- 刀刃恰好穿过顶点时横向微移重试（避免退化环）；产生的碎屑环（<3 粒或面积过小）直接丢弃。
- 焊缝已收紧成零长线段，改用"刀刃到焊点距离 < 6"判切。

### 3.4 授关的两条守恒律（重要）

1. **面积守恒**：目标面积 ≈ 身体面积 × 该阶段的压力系数。
2. **周长守恒**：目标周长 ≈ 身体轮廓周长（弹性膜允许 ~10% 拉伸）。

两条都必须满足，目标才物理可达。`tests/levels.test.js` 机械校验第一条，
`tests/solve.test.js` 用"作者解"（模拟理想玩家的软手掌抓取 + 幽灵跟随 + 过冲）
验证真实可达性。

## 4. 相似度判定

### 4.1 2D

每 100ms 计算一次；显示值指数平滑；蓄力判定用原始值。

1. **对齐**：质心平移 + 旋转粗到细搜索（24 角 + 3 轮细化；允许镜像时双向）。
   候选角按**外形+管道综合分**排序——对称外形（六边形/圆）多个旋转 IoU 并列，
   只有管道能区分。
2. **外形分**：非零环绕扫描线栅格化到 96×96 网格（自交/折叠环按并集填充），
   与目标网格算 IoU，再映射 `(IoU − 0.30) / (0.92 − 0.30)`（手工塑形到 IoU 0.92
   即算满分）。默认**不做尺度归一**——大小也要摆对，防"捏小团骗分"。
3. **管道分**：同一变换下，玩家管道链与目标管道做**对称 Chamfer 距离**
   （对参数化/切点位置不敏感），按目标外接半径归一。
4. **拓扑门**：管道 (链数, 环数) 必须与目标一致，否则管道分 ×0.25 并显示
   "⚠ 管道结构不符"。这是"这个目标要求你切/不切某根管道"的表达方式。
5. **合成**：`总分 = 100 × (0.6×外形 + 0.4×管道)`（每目标可调权重）。

### 4.2 3D

体素占据 IoU（20³，z 列奇偶填充）；只做质心平移对齐（姿态固定，幽灵线框指引），
映射 `(IoU − 0.25) / (0.80 − 0.25)`；管道 3D Chamfer；同款拓扑门。

### 4.3 达标 cutoff

- 默认 **85**；教学关 80；发现型目标（如泄气软袋塑形）75–83；3D 78。
- 读值 ≥ cutoff **连续保持 3 秒**（蓄力环可视化）；
  迟滞 1.5 分——短暂抖落到线下不清零，只暂停累计。
- 每个 cutoff 都有机械保证：完美形状得分 ≥ cutoff + 5，
  静息态（标注 `_restBelow` 的目标）得分显著低于 cutoff，
  核心目标作者解得分 ≥ cutoff。

### 4.4 动态幽灵

目标轮廓按当前最优变换**贴着玩家的软体**渲染（金色虚线）——残差一目了然，
玩家不需要在脑子里做旋转对齐。

## 6. 反作弊设计

- IoU 天然抵抗"捏小团"（交集小 → 分低）；不做尺度归一加倍防御。
- 拓扑门防"不切管道硬掰外形"。
- 蓄力 3 秒防"甩过去蹭一下"。
- 旋转搜索按综合分排序，防"转到管道对不上的对称角"。

  切割二分、逐关截图。

## 8. 已知取舍与路线图

**v1 取舍**：无自碰撞（极端对折会穿透）；3D 不支持本体切割/粘合；无音效；
切割一刀只处理第一个进入的岛。

**路线图**：3D 平面切割（网格手术）＋3D 粘合；自碰撞；更多物性
（塑性蠕变、各向异性膜、漏液管道）；关卡编辑器（关卡已是纯数据）；
计分排行（剩余时间 + 刀数）；音效与触觉反馈。
