# 生物物理精修循环宪章（第二期 · Planner / Generator / Evaluator 共同契约）

## 目标

用户对生物版《活体标本》的判词：**"物理太假了"**。本期循环集中改造**生物版的物理行为**，
让这块组织拉起来、切开来、跳动起来都像活体软组织，而不是果冻弹簧。
时限 **4 小时**（deadline 见 state.json），预计 3–4 轮。

## 可疑的"假"点（第一轮 Planner 自行诊断确认，不限于此）

1. **纯弹性、无粘性**：真实软组织是粘弹性的——蠕变、应力松弛、迟滞回环；现在松手立刻弹回、拖动像拉橡皮筋。
2. **线性刚度**：软组织应力-应变是 J 形曲线（低应变极软、高应变胶原募集急剧变硬）；现在恒定柔度，大变形不"锁死"。
3. **弹簧式回振**：组织高阻尼、几乎无振铃；现在松手有果冻抖动。
4. **肌肉是死弹簧**：真实肌肉有主动收缩动态（张力随长度变化、缓慢发力）；现在是固定 rest 系数的静态约束。
5. **放血是数值滑步**：现在切断血管 = 面积目标 0.4s 线性下降；真实是搏动性失血——随脉搏一股一股地漏，逐渐失压、脉搏减弱直至停止。
6. **无组织撕裂**：过度拉伸的膜应该局部撕开（可选，风险高，Planner 裁量）。

## 架构铁律：材质档案（Material Profile）

- 引擎（src/engine/）**允许改造**，但一切新物理必须是**默认关闭的可选特性**（config 开关/参数，
  默认值 = 现行为）。**lab 主题与全部既有测试必须逐位不变**：84+ 项测试全绿、
  solve 六基线（87.685980/81.138015/87.293848/50.475188/78.903977/90.469726）逐位一致。
- bio 主题通过 themes.js 的物理档案（fx.physics 之类）在会话层把新特性打开并配参。
- **bio 档案必须有自己的可达性保证**：新增 tests/solve-bio.test.js（作者解在 bio 物理下仍能过
  各关 cutoff——cutoff/关卡数据不许动，达不到就调 bio 档案参数，不许改关卡）。
- 两主题物理不同是本期的设计意图（bio 更真实、手感不同），但**判定体系（相似度/cutoff/时限）完全一致**。

## 角色契约（同第一期，评分量表更换）

- **Planner**（只读）：读本宪章 + 上轮 evaluation + 代码，产出 plan.md（3–6 任务、验收、禁改清单）。
  第一轮必须先做**诊断**：在 bio 主题下实际测量"假"在哪里（探针数据），再对症开方。
- **Generator**：实施 + 硬门（node --test 全绿 + smoke PASS + solve 基线逐位一致 + 新增 bio 可达性测试绿）+ changelog + 中文 commit + push。
- **Evaluator**：**切到 bio 主题**用 Playwright 真人式游玩，重点做"物理手感实验"：
  缓拉-保持-松手（看蠕变与回弹曲线）、快拉快放（看阻尼振铃）、小拉 vs 大拉（看非线性）、
  切血管全程观察失血动态、拖动肌束感受主动收缩；截图+读数曲线佐证；按新量表打分。

## 评分量表（1–10，五项）

1. **组织拉扯真实感**（粘弹性：蠕变/松弛/迟滞可感）
2. **阻尼与定形**（无果冻振铃；大变形后缓慢回复而非弹射）
3. **血管行为**（脉搏可感、失血动态真实、失压渐进）
4. **肌肉行为**（主动收缩感、力-长度特性、剪断释放自然）
5. **可玩性无回归**（bio 下各关仍可过、手感不烦人、工程版无损、无崩溃）

终止：五项全 ≥8.5，或 4 小时 deadline，或预算尽。收尾：终局总结 + zip 交付 + 删复活 cron。

## 硬门（每轮 Generator）

1. `node --test 'tests/**/*.test.js'` 全绿（含新增 bio 测试）；
2. solve 六基线（lab 物理）逐位一致；
3. `node tests/e2e/smoke.mjs` PASS（默认 lab）；
4. bio 可达性测试绿（solve-bio）；
5. 中文 commit + push；changelog 记录参数与探针数据。

## 红线

- bio 主题内生物词汇是卖点（血管/肌腱/组织尽管用）；lab 主题文案/表现不许沾染。
- 新物理必须数值稳定：暴力拖拽 10 秒不 NaN、不爆炸（沿用 xpbd 测试标准，为新特性加同款测试）。
- 性能：60fps 预算内（新特性每帧开销与现有同量级）。
