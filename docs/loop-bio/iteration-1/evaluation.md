# 生物物理循环 第 1 轮 · Evaluator 评测（用户视角）

判词回顾：用户说"物理太假了"。本轮 Generator 交付了「粘弹性地基」——SLS 蠕变、J 形硬化、
阻尼 0.92、搏动性失血。我切到 **bio 主题**做了五组"物理手感实验"，全程 Playwright 真人式游玩，
截图 16 张（`docs/loop-bio/iteration-1/shots/eval-*.png`，每张亲自看过），并用引擎探针读了数值曲线。

**一句话结论：不再是"果冻弹簧"了——血管这块已经像活体，是本轮最亮的一维；但组织的粘性要"钉住一端"
才摸得到，随手一拉仍偏弹性；肌肉本轮按计划没做。整体从"太假"抬到了"及格偏上、局部惊艳"。**

关键前提（影响多项打分）：**bio 的新物理只有在一端被固定（图钉/锚点）时才真正显现。**
自由地抓住一处拖拽，整块标本会随手平移（无对侧反力 → 内部几乎不建立应变 → 蠕变/硬化都不触发），
手感与旧弹性版几乎一样。L1 的设计手势本就是"钉住一端、拖另一端"，所以我按设计手势（钉一端）
复测了蠕变与硬化——下面数据均来自"钉一端"的正确手势，同时把"随手拉不显现"作为独立发现记录。

物理隔离已验证：lab 会话 `damping=0.982 / viscoelastic=false / pulse=false / nCreep=0`，配色与工具
（🖐牵拉/✂️切割/🔗粘合）逐位还原；bio 会话 `damping=0.92 / viscoelastic=true / pulse=true /
nCreep=123`。全程 **console error = 0**。

## 1. 组织拉扯真实感（粘弹性）— 7.5

**蠕变体验（钉右端、拉左端、按住 5 秒）**：正确手势下蠕变清晰可见。
- 按住不动的 5 秒里，组织**在手里继续延展**：被握住的一端 `left 128.6 → 122.9 → 120.8`
  （手固定，边缘仍多爬了约 8px），整体宽度 `326.7 → 332.3 → 334.4`；边约束的平均 `rest/rest0`
  从 `1.011 → 1.039 → 1.047`，最受力的边吃满 `restHi=1.5` 夹。这是标准 SLS"流动"。
  见 `eval-02-creep-hold-0s.png` vs `eval-03-creep-hold-5s.png`（同一纺锤体，5 秒后更瘦长；
  顺带把目标 1 保持达标锁了，说明形状能稳稳 hold 住）。
- **松手回弹曲线**教科书级："先快回大半、再缓慢愈合"完全成立：
  被握端 `120.8 →(0.5s) 216.9 →(3s) 246.2 →(8s) 260.6`，出厂静息 `264.7`——
  0.5 秒内先弹回约 67%，随后 7.5 秒缓慢愈合到 **97% 归位、残余 ~3%**，**无永久塑形**；
  `restRatio` 同步衰减 `1.047 → 1.036 → 1.010 → 1.002`。见 `eval-04-release-0p5s.png`
  （已弹回大半的近菱形）、`eval-05-release-8s.png`（回到六边形静息）。

**扣分点（重要发现）**：**核心卖点被"钉住"手势藏住了。** 不钉住、随手抓一处拖，整块标本平移，
内部应变 `maxRestRatio` 仅 ~1.06（首轮自由拖数据），蠕变/松弛几乎不触发，读作纯弹性滑移——
与 lab 无异。一个第一次上手、还没学会钉图钉的玩家，感受不到"活体的粘"。
建议：给未钉住的标本一个隐形中心锚 / 提高内部应变传递，让"随手拉"也建立应变；或在教学上更早把
"钉一端"前置。

## 2. 阻尼与定形 — 7.5

- **阻尼 0.92 确认。** 快速大幅拉开立即松手：自由甩出后回家轨迹近单调（质心序列仅 1 次反向），
  温和释放（Generator 探针 +100px：过零 0、0.62s 止息）——彻底脱离旧版"果冻回摆 2.65s"。
- **扣分点**：把标本钉一端、再**极端猛拉（240px）瞬放**，被放的自由端仍有 **2–3 次衰减回摆**
  才定（边缘 `323 → 217 → 279 → 256`，振幅 67→39→23px 递减，约 1 秒定形）。不是"最多一次过冲即定"
  的理想，但幅度快速衰减、远好于果冻。见 `eval-06-definition-a.png` / `eval-07-definition-b.png`
  （猛放瞬间标本被甩成大团块的暂态，随后收拢）。
- 另注：心搏让静息标本有恒定 ±1px 的"呼吸"微动（`applyPulse` 的 1.8% 面积调制，属**有意**的活体感，
  非缺陷），但它让"完全静止定形"永远差一点点。

## 3. 血管行为 — 8.5（本轮标杆）

**失血全程（L2 切断环状血管后什么都不做，连续 5 帧）**：搏动性失血完全达成，是最有说服力的一维。
- 切前：单岛 `rel=1.35`（`goal 37984 / base 28136`，鼓胀充血）。一刀下去标本被二分，环管断成两瓣。
- **一股一股失压**：`pressureGoal` 先被抬回切前水平，再随心搏**离散地一跳一跳**下台阶——
  `rel 1.095 → 1.095 → 0.947 → 0.849 → 0.800`，面积同步阶梯式收缩
  `18046 → 15800 → 13757 → 12325 → 11512 → 11258`。不是旧版 0.4s 线性滑步。
- **血滴随心搏喷发且逐次减弱**：每次收缩相喷一股血滴，强度递减——在场血滴粒子
  `sparks 62 → 46 → 46 → 46 → 32 → 0`，见 `eval-10..14-bleed-*.png`：断口一簇血珠 → 环管张成
  透镜状、血珠成串向下坠落 → 压到 29.4 时仍有残血下滴。
- **脉搏随失压减弱直至停止**：`rel` 跌破 0.90 后脉搏 fade→0，`bleeds 2 → 0`，最终稳在 `rel=0.80`
  静止不再搏动。与设计一致。
- 小扣分：压降台阶在数字上偏平滑（要盯着才数得出 3–4 跳），血喷是更直觉的线索；台阶再"顿挫"一点更好。

## 4. 肌肉行为 — 3.0（本轮按计划未做）

主动收缩留后轮：`pipeStyles` 覆盖表已接线但为空。L3 肌腱仍是静态 restFactor 约束——
能把肌片折弯（`eval-16-regression-L3.png` 肌腱可见、把板材蜷成鼓包），但**无力-长度特性、
无缓慢发力、无主动张力动态**，剪断释放沿用旧 cableRecoil。这是循环正常节奏，照实低分，不是失误。

## 5. 可玩性无回归 — 8.5

- L1/L2/L3/L4 在 bio 物理下均正常起跑、可玩；我在实验里顺手把 L1 目标 1 达标锁定，说明新物理未破坏可达性
  （与 changelog 的 solve-bio 全绿一致）。
- **lab 逐位不变**：切回工程主题，配色/文案/工具全还原，solver 三字段回到出厂
  （`eval-15-lab-control.png` 绿色六边形，拉-放后完全弹性归位、无蠕变残留）。
- 手术刀切割、泄压、二分岛均工作；**全程零 console error、零崩溃**。
- 轻微烦人点：心搏呼吸微动 + 未钉住标本的"归位滑行"仍在，但不影响操作。

## 下一轮最值得做的 3 件事

1. **让粘弹性"随手可感"**（性价比最高）：当前蠕变/松弛/硬化全被"钉一端"手势门控，随手拖只平移不建应变，
   核心卖点摸不到。给自由拖拽也造出内部应变——隐形中心/软锚、或降低整块刚性平移、或提高握持patch的
   应变传递——让不钉图钉的玩家一拉就感到"这块肉会流、会黏"。

2. **补上 J 形硬化的"锁死"手感**：物理力是 J 形（Generator 探针 F(2.0)/F(1.1)=24×），但交互位控下
   刚性的手锚能把膜拉到 `strain 2.14`（细成一根丝，`eval-09-harden-max.png`），"拉不太动"只靠边界泛白
   在视觉上撑着，触觉几乎没有（reach/手位移仅从 105% 降到 89%）。提高 hardenK / 在极高应变追加近刚性
   夹（rest 硬上限或单侧接触），让"锁死"真的拉不动。泛白本身已同步且好看，保留。

3. **开工肌肉主动收缩（L3 肌腱）**：力-长度特性 + 缓慢发力 + 剪断释放的回弹节律，把最低分维度从 3 分抬起来。
