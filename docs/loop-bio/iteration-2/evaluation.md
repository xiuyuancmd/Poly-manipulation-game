## 4. 肌肉行为 — 5.5（本轮主战场，+2.5）

三组实验逐条核查（activation / rest 均为引擎探针实读）：

### 剪断释放 — 失神经（**做得最好，招牌一击**）
`eval-06→09`。手术刀从标本外向下划一刀切断上肌腱：
- **远端瘫软褪白**：切出的两段 `den=true`，activation `a: 0.31 → 0.09 → 0.007`（逐步归零），
  `rest: 12 → 13.6 → 14.2`（松弛迁向 `slack·rest0c=14.2`），肌腱在画面上褪成灰白软条。
- **近端痉挛回甩**：切断瞬间（`eval-07`）一道亮青色鞭影（cableRecoil + spawnWhip）——
  断端"啪"地弹开，是肉眼可见的痉挛。
- **身体因失去张力舒展**：上肌腱失张后，板材顶缘缓慢外舒（`eval-08→09`，高度/曲率回落）。
- 未切的下肌腱仍维持 `a≈0.35`。切断触发"脉管结构不符·读数压至 25%"——与"千万别切肌腱"的
  关卡设计一致，是正确后果，非缺陷。
这一段完全达成宪章"剪断释放自然"，且是整块肌肉最有说服力、最难忘的瞬间。

### 力-长度 — 存在但**手感极弱**
`eval-01` vs `eval-02`。钉住两端把肌片拉平：肌腱确实"松劲"（约束层探针对：s≈1→a>0.98、
s=1.8→a=0.35），但在真实 L3 里板材结构刚度把肌腱**恒定顶在 s≈1.8 的满拉状态**，activation
拉平前后仅 `0.377 → 0.351`——"褪色变淡"技术上有、肉眼几乎看不出（粉→粉）。宪章要的"拉平比
想象容易、肌腱褪色"这半条只兑现了"容易"，"褪色"没兑现。

### 强直上升 — 数学在、**游玩中不可见**
`eval-03→05`。松开图钉后本应"先淡后红、约 0.5–1s 逐渐收拢"。实测：松手 t=0/0.45/1.15s
三帧 activation **恒为 0.35 纹丝不动**，板材只回到出厂那点浅浅的自然弯（≈`eval-01`），
**没有 pale→red、没有渐进收拢**。根因：主动肌肉在 a=0.35 时既弱又被 softK 软化（柔度×1.98），
赢不过板材刚度，平衡点永远落在力-长度曲线地板，肌腱全程 pale、永不发红。riseK 2.0 的强直
上升沿只在单元测试里（人为把肌腱压到 s≈1）才看得到，L3 玩不出来。

**小结**：肌肉从"静态死弹簧"变成"剪断有生物后果、渲染为活肌肉"的真组织——这是实打实的进步；
但宪章第 4 维的核心"主动收缩感"（缓慢发力、收拢发红）在正常游玩里没真正打出来，故给 5.5 而非更高。

## 上轮三诉求处置核查

1. **开工肌肉主动收缩**（上轮头号建议）：**做了，部分兑现**。失神经/剪断释放优秀，
   力-长度/强直上升在 L3 几何下被压在地板不可见——见上文第 4 维。

2. **让粘弹性"随手可感"**（证伪砍除 · dashpot）：**服气砍除**。均匀刚体平移下粒子无相对速度，
   dashpot 不产生应变、对"随手拉不黏"这个现象根本无效，且注入惯性打穿了 L2-2 的 solve-bio 硬门
   （plan.md 证据）。砍的是**错误机制**，判断正确；但上轮那条底层诉求（不钉图钉也能感到组织会流）
   **仍未解决**，正解应是中心软锚 / 应变传递而非阻尼，留后轮。

3. **补 J 锁死手感**（证伪砍除 · hardenK）：**服气砍除**。上轮"拉成一根丝 strain 2.14"来自
   **面积保积把板条压细**（压力/面积约束），不是距离约束伸长；hardenK 作用在距离约束的伸长项上，
   对"变细"这个自由度无效（plan.md 证据）。诊断精准，砍得对；"锁死触觉"要另用面积地板 / 自接触实现，留后轮。

两项证伪都是技术上站得住的——提出的机制确实不会奏效，Generator 选择不带病上线、把预算压到
最高杠杆且探针证明安全的肌肉上，是**正确的收官取舍**。我服气。

## 终评结论：现在还"假"吗？

**比上轮更不假了，但招牌动作仍差一口气。** 血管是真活的（搏动、喷血、失压）；组织的粘弹性是
真的、只是被"钉一端"手势门控；肌肉这轮从"死弹簧"变成"剪断会瘫软褪白、断端会痉挛回甩、渲染成
活肌肉"——**用户拿刀划断一条肌腱的那一刻，'假'字是彻底破掉的**。遗憾在于：肌肉平时不会自己
"发力、收拢、发红"，它在 L3 里始终是一条被拉长的浅粉软条，主动收缩的幻觉主要停在纸面/单元测试。
一句话：**不再"太假"，血管与失神经局部惊艳，主动收缩仍偏静态。**

## 剩余差距清单（供未来迭代）

1. **主动收缩打不出来（最大缺口）**：L3 关卡几何把肌腱恒定拉到 s≈1.8，activation 卡在力-长度
   地板 0.35，肌腱全程 pale、松开图钉不回缩红亮、强直上升沿玩不出。需让肌肉能赢过板材刚度
   （提高 flMin / 降 slack / 软化板材 / 或专设一个"肌肉自发缩短"的姿势关卡），才能在游玩中
   看见"缓慢发力、收拢发红"。

2. **力-长度对比太弱**：拉平前后 activation 仅 0.377→0.351、颜色几乎不变。需要更大的力-长度
   动态范围或更强的活性染色梯度，让玩家真能"看出"肌肉被拉长时松劲褪色。

3. **上轮两大手感遗留仍在**（本轮证伪砍除、未修）：① 随手拖不建应变、粘弹性被"钉一端"门控
   （正解：中心软锚/应变传递）；② J 锁死触觉缺失（正解：面积地板/自接触）。另加宪章高风险可选项
   组织撕裂、以及肌肉自主节律收缩，均未做，留将来。
