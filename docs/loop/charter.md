# 精修循环宪章（Planner / Generator / Evaluator 共同契约）

## 目标

把《形变工坊 PolyForm》从"能玩的原型"精修到"现象级"品质。用户的两条核心批评：
1. 软体不像任何真实世界的材料；
2. 内部管道太简单，与本体没有结构联系。

## ⚠ 红线（违反 = 本轮不合格）

**杜绝一切生物联想。** 不许出现血管/肌腱/皮肤/呼吸/心跳/愈合/器官等任何生命隐喻——
视觉、文案、动效、音效全部必须是纯物理/工程的。

## 主题定位：《软体试验台》

软体 = 材料实验室里的工程软材料试件（硅胶/凝胶浇注件）；管道 = 嵌入其中的机械子系统。

| 类型 | 工程身份 | 表现（全部对应真实物理现象） |
|---|---|---|
| pressure | 气压回路 | 充气使膜面绷紧发亮；切开→气流粒子+嘶声+塌陷+松弛褶皱 |
| contractile | 张紧缆线 | 受拉绷直、端点应力集中凹陷；剪断"铮"声+回甩 |
| rigid | 桁架杆 | 金属质感硬直描边，受压顶起周围材料 |
| brittle | 玻璃/陶瓷导管 | 应变升高→应力泛白预警；断裂脆响+碎屑 |
| 膜/本体 | 硅胶浇注件 | 半透基体透出管路、湿润高光、受拉应力泛白、受压细褶皱、指压凹陷、松手阻尼回振、切口弹性回缩 |

**材料感来自"对交互的物理响应"，不靠闲时动画**：静止时纹丝不动；表现力全部发生在施力/切割瞬间。管道颜色保持一致（隐藏物性不直接泄密），可观察线索必须物理正当（缆线绷直、脆管泛白、气腔切开才现形）。

配套方向：WebAudio 合成工业音效（拉伸吱声/snip/hiss/弦响/仪器提示音）、
关卡换皮为编号试件与质检语境、HUD 实验仪器风、手感多汁化（跟手、回振、滞刀感）。

## 硬门（每轮 Generator 必须满足才算完成）

1. `node --test 'tests/**/*.test.js'` 全绿（含守恒审计、作者解可达性）。
2. `node tests/e2e/smoke.mjs` 通过。
3. 物理参数变动必须同步验证作者解测试仍过。
4. 每轮至少 1 个 git commit（中文信息），并尝试 `git push -u origin claude/polygon-shape-puzzle-nzi6lj`（403 是已知问题，失败不阻塞）。

## 角色契约

- **Planner**（只读）：输入 = 本宪章 + state.json + 上一轮 evaluation.md（首轮没有）。
  输出 = 本轮 plan.md：本轮主题、3–6 个给 Generator 的具体任务（含文件与验收标准）、
  明令不许动的部分。任务量控制在一个 agent 60 分钟内可完成。
- **Generator**：输入 = plan.md。严格按任务实施；跑硬门；写 changelog.md
  （做了什么、没做什么、为什么）；commit。
- **Evaluator**：输入 = 本轮 changelog.md。起服务器 + Playwright 像真人一样玩
  （慢速拖拽、犹豫、误操作、读提示；L1–L3 必玩 + 本轮新内容），
  关键瞬间截图到 iteration-N/shots/ 并亲自看图；输出 evaluation.md：
  五项评分（1–10）：材质可信度 / 结构-本体力学连贯性 / 操作手感 / 引导清晰度 / 惊喜时刻，
  外加红线检查（发现生物联想 = 该项直接 3 分以下），
  每项都要给出**具体的、可执行的**改进意见（毒舌但对事）。

## 终止条件（协调者判定）

五项全 ≥ 8.5，或到 deadline（state.json），或预算耗尽。
超时/结束时：终局总结 + 打包 zip 交付用户 + 删除复活 cron。
