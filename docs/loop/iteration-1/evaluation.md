评测方式：Playwright 无头 Chromium，按"第一次玩的真人"流程走 L1 → L2 → L3 → L6：
犹豫的小幅慢拖、按提示做目标、L2 先傻傻乱按 ~40 秒再学会切割、切错位置、泄压后再按压观察。

## 1. 材质可信度 — 6 / 10

**看到了什么**

- `eval-l2-inflated.png`：充压试件整圈边界泛白 + 亮边高光，确实读作"绷紧的膜"，这是本轮
  最成立的材质瞬间；`eval-l2-deflated.png` 泄压后轮廓垮成不规则软袋、环管散成下垂开链、
  读数从 77 跳水到 38——充压/泄压两种材料状态的对比是真实可信的。
- `eval-l1-firsttouch.png`：半透基体让金色虚影透体可见，管路带深色孔道衬底、确实读作
  "嵌在材料里"，比"画在表面"强一档。
- `eval-l6-drag.png / eval-l6-rotated.png`：3D 关新配色无异样，但也**没有任何材质层**——
  纯平色三角面，和 2D 的"硅胶浇注件"叙事完全脱节。

**哪里出戏**

1. **褶皱刻线在正常游玩分辨率下基本不可见。**`eval-l2-deflated-press.png` 里我按压泄压软袋，
   泄压感全靠轮廓垮相撑着，承诺的"压缩细褶皱"肉眼找不到。Generator 自己也承认"偏含蓄"——
   含蓄到等于没有。
2. **抓取凹陷太弱。**`eval-l1-firsttouch.png` 里抓点只有一个黄点，30px 暗斑在深绿基体上
   几乎分辨不出，"手指按进凝胶"的关键触感没传达出来。
3. **静止的 L1 像一块平涂色块。**湿润高光在六边形上找不到存在感；只有 L2 充压态高光可辨。
   "硅胶"要靠 L2 才成立，L1 作为第一印象关，材质表达最弱。

**给 Planner 的建议（按影响排序）**

1. 褶皱与凹陷的对比度直接翻倍起步：褶皱刻线加粗加亮（或改用短阴影对），凹陷暗斑加深
   并配环形受压亮边——在 960px 画布上眯着眼能看见才算数。
2. 泄压态整体降饱和/降亮 5–10%（读作"没气了的皮囊"），与充压态的泛白拉开材质档位。
3. 3D 关至少移植"受拉泛白 + 简单朝向明暗"两层，否则玩家从 L5 进 L6 会觉得换了个游戏。

## 2. 结构-本体力学连贯性 — 6.5 / 10

**看到了什么**

- L2 的因果链完整成立：环管充压把本体撑鼓（`eval-l2-inflated.png`）→ 怎么按都按不瘪
  （乱按 40 秒读数最高 81，`eval-l2-mash.png`）→ 从外切断环管 → 立刻泄压塌陷 +
  「⚠ 管道结构不符」（`eval-l2-deflated.png`）。管路不是贴图，是真的在做功。
- `eval-l3-pull.png`：两条缆线真实把板材拽弯；我拽左端对抗拉力时，靠近抓点的缆线松弛
  弯垂、另一条仍绷直，板材下缘受拉整段泛白——"可观察差异只来自力学状态"确实做到了。

**哪里出戏**

1. **试件浮在虚空里，越玩越漂。**`eval-l2-mash.png`：乱按 40 秒后整个试件从画面中心漂到
   左上，离目标虚影越来越远。实验室试件应该在台面/夹具上，现在像一块失重果冻——
   这直接违背"软体试验台"的世界观，还引发了后述的切割挫败。
2. 泄压后软袋轮廓有轻微多边形噪感、底部小叶瓣近似自叠（`eval-l2-deflated.png`），
   松垮感成立但边缘欠"厚度"。
3. Generator 遗留的 L4/L5 静息态管路顶出边界问题本轮未处理（物理冻结，可理解），下轮必须清。

**给 Planner 的建议**

1. 给每关加"工作台锚定"：底部台面/夹具视觉 + 轻微回中（或质心缓漂回锚点），
   既救世界观又救操作（见下条）。这是本轮暴露的最高优先级结构问题。
2. 泄压软袋的边界渲染补一层"松弛下垂"处理（如边界描边变虚变哑光），掩多边形噪感。

## 3. 操作手感 — 5.5 / 10

**看到了什么**

- 慢速拖拽全程跟手、无迟滞，局部形变自然扩散；双击钉住即时生效（`eval-l1-hold.png` 红圈钉）。
- **真实挫败复现**：乱按导致试件上漂后，我按原始坐标"从上方"下刀——刀起点已在漂移后的
  体内，切割被拒。拒刀确实有 toast「只能从软体外部下刀」（2.2 秒后消失），但它出现在
  屏幕底部、离刀口十万八千里，我第一遍完全没注意到，只看到"划了一刀，啥也没发生"
  （`eval-l2-mash.png` 之后那刀）。第二次从真正的体外下刀才成功。
- L1 目标一：钉左端、抓右顶点外拉到位并保持 3 秒，读数仅 71→74（达标线 80，
  `eval-l1-hold.png`）。单点牵拉对全局形状的影响小，读数梯度平得让人怀疑自己方法错了。

**哪里出戏**

1. 拒刀反馈"有但等于没有"：位置错、消失快、无现场痕迹。
2. 用力和进度不成比例（L1 拉满只 +3 分），玩家无法从读数感知"方向对了"。
3. 全程静音。切割、泄压、钉住、达标全无声音，"多汁"无从谈起（宪章方向，本轮未排期，如实记）。

**给 Planner 的建议**

1. 拒刀就地反馈：在刀口画一道 0.5 秒即褪的白色刮痕 + 刀口旁小字提示，
   toast 可留可去——反馈必须发生在玩家眼睛看着的地方。
2. 工作台锚定（同上）根治"越按越漂、按原位置下刀落空"的连环坑。
3. WebAudio 三件套先行：切割 snip、泄压 hiss、达标 chime——成本最低、手感增益最大。

## 4. 引导清晰度 — 6.5 / 10

**看到了什么**

- 引导链路完整：开关 intro toast → 右栏目标名 + 虚影缩略图 + 提示文案 → 40s/80s 渐进提示
  （乱按期第 40 秒准时弹出「抓住上下两侧往里按」且确实有用，`eval-l2-mash.png`）→
  外形/管道双条 + 「达标线 85 · 保持 3 秒」→ 「⚠ 管道结构不符」拓扑警告。
  切换切割工具时还有一次性教学 toast「从软体外面按住，划一条线切进去」。骨架是好的。
- `eval-menu.png`：菜单干净，工程叙事统一，操作说明一行讲全。

**哪里出戏**

1. **L2 软锁无提示。**我在目标一（满压凸壳，需充压）期间切断了环管——此后该目标物理上
   不可达成，游戏只给「⚠ 管道结构不符」，不告诉我"这局废了，重开吧"。真人会在 38 分上
   干耗到超时。
2. 蓄力环在读数低于达标线时零存在感：不达线的玩家根本不知道"保持 3 秒"机制长什么样。
3. L6 开局读数 **4**（`eval-l6-drag.png`）：没有任何解释为什么这么低，对刚进 3D 关的
   玩家是一盆冷水（拓扑警告有帮助但不够）。
4. 乱按玩家在 0–40 秒之间是提示真空期，L2 恰好是最需要早期点拨的关。

**给 Planner 的建议**

1. 加"不可达成检测"：当前目标要求充压/完整管路而试件已泄压/断裂时，弹明确提示
   「试件已泄压，本目标无法达成——重开试件」。一行判断，救掉最惨的挫败。
2. 读数首次越线时给一次性强提示（环高亮 + toast「保持住！」），教会保持机制。
3. L2 把第一条提示从 40s 提前到 ~20s，或首次按压回弹到原形时就触发「按不动？想想里面
   那圈管路」。

## 5. 惊喜时刻 — 5.5 / 10

**看到了什么**

- 本轮唯一的 wow：切断环管瞬间——软袋垮塌、环管散成开链下垂、读数 77→38 跳水、
  toast「嘶——有什么东西泄气了……」四件事同时发生（`eval-l2-deflated.png`）。
  作为因果惊喜是真的，第一次见会"哦！！"一声。
- L3 拽着板材对抗缆线、松手回弹也有一点"活物感"（工程意义上的）。

**哪里出戏**

1. wow 只有状态 A→状态 B 的瞬切 + 一行字：没有嘶声、没有气流粒子、没有 0.3 秒的
   塌陷过程动画。最贵的一个瞬间目前是"哑剧"。
2. 六关只有这一处惊喜。L1 全程平淡（作为第一关可接受但高光欠奉），L6 的斜撑剪断
   理应是第二个 wow，本轮未评到位。

**给 Planner 的建议**

1. 把泄压做成"事件"：hiss 音效 + 切口喷出 10–20 个气流粒子 + 内压在 0.3–0.5 秒内
   衰减（渲染层插值即可，不必动物理步进）+ 褶皱从切口向外扩散。这一条做好，
   本项直接 +2 分。
2. 缆线剪断的"铮 + 回甩"（宪章已列）做出来，给 L3/L5 第二个高光。
