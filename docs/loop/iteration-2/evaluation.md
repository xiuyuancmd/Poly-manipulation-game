# 第 2 轮 · Evaluation（用户视角评测）

评测方式：Playwright 无头 Chromium，按真人流程玩 L1（完整含蓄力环）→ L1 乱拖 15 秒
→ 体内起刀 → L2 按压后切环（前/后 0.2s/后 1s 三帧）→ 故意软锁等 6 秒 → L3 拽缆线

## 1. 材质可信度 — 7 / 10（+1）

**看到了什么**

- 抓取凹陷终于能看见了：`eval-l1-pull` 右侧抓点周围一圈明显暗斑 + 受压亮弧，
  拉拽处材料尖出、边缘泛白，"手指按进凝胶"这次传达到了。
- 泄压材料档位拉开了：`eval-l2-precut` 充压态白亮绷紧膜边 vs `eval-l2-cut1s`
  松垮软袋——体色变暗变哑、边缘描边从亮白变哑青、底边出现短刻线褶皱。
  三帧连看，材料从"充气膜"变成"没气的袋子"，可信。
- `eval-l1-clamp`：静止态纹丝不动，表现力全在交互瞬间，符合宪章。

**哪里出戏**

1. **降饱和仍偏含蓄**：单看 `eval-l2-cut1s` 不对照前帧，很难说出"它变灰了"。
   幅度还可以再加 5% 左右，或叠一层哑光（降低边缘高光强度）更能读出"没气"。
2. **L1 静止态还是一块平色块**：湿润高光在六边形上仍然找不到，第一印象关的材质
   表达依旧最弱（上轮已提，本轮计划未排）。
3. **泄压袋右下偶发小叶瓣近似自叠**（`eval-l2-cut1s` 右下角小瓣），松垮感成立
   但局部有多边形噪感。
4. 3D 关依旧零材质层（本轮明令不动 render3d，不扣新分，但玩家体验的断层还在，
   `eval-l6-3d` 仍是平色三角面）。

**给 Planner 的建议**

1. 泄压降饱和再加一档，并把泄压岛的边缘高光强度乘 0.5——"哑光"比"变灰"更便宜也更准。
2. L1 给基体加一条极简高光带（沿轮廓上缘 20% 亮度渐变），成本一层描边，救第一印象。
3. 泄压袋的凸包小叶瓣：渲染层对边界做一次 3 点滑动平均即可掩掉自叠噪感，不必动物理。

## 2. 结构-本体力学连贯性 — 7.5 / 10（+1）

**看到了什么**

- **失重果冻问题解决了。**乱拖 15 秒（6 段乱抓乱甩）后松手，质心偏移仅 19px，
  3.5 秒内滑回 0.0px（数值实测）；`eval-l1-drift-back` 里试件稳稳落回卡爪框内。
  上轮"越玩越漂、按原位下刀落空"的连环坑被根治。
- L2 因果链现在有"过程"：充压撑鼓（79 分怎么按都不瘪）→ 切环 → 0.2s 时膜面
  半塌、粒子从切口喷出 → 1s 塌陷完成 → 环管散成下垂开链。管路做功全程可见。
- `eval-l3-whiten`：拽住板材左端对抗缆线，受拉下缘整段泛白、缆线弯垂松弛，
  力学线索照旧只来自力学状态。

**哪里出戏**

1. **回中不回转。**乱拖后试件停在约 40° 斜姿（`eval-l1-drift-back`），位置归零了
   但方向永远歪着——轴对齐的卡爪框里卡着一块斜试件，"夹具"的说服力自己打了折。
   相似度对旋转不变，均匀旋转和均匀平移一样物理无害，没理由不一起回正。
2. **卡爪框读感更像相机取景框**：四个细 L 角 + 中心十字，悬在网格上，没有台面、
   没有夹块厚度、没有影子。它解释了"为什么会滑回去"，但不太像"检测台夹具"。
   （`render2d.js` drawClampFrame，纯 4 段折线。）
3. L2 泄压袋偶发底部小瓣自叠（同上）；L4/L5 静息管路顶出边界的遗留问题本轮计划
   未排，下轮必须清（第二次记录）。

**给 Planner 的建议**

1. 空闲回中时同步缓回旋转：对 rest 姿态做最小二乘刚性对齐（Kabsch 2D，一个 atan2），
   限速如 20°/s，均匀旋转全体粒子+prev 位置，物理与评分同样零扰动。
2. 夹具加实体感：L 角加粗成小夹块（双线+内侧短齿），框底加一条工作台横带或
   试件正下方一条淡椭圆投影——三笔以内，"台面"就成立了。

## 3. 操作手感 — 6.5 / 10（+1）

**看到了什么**

- **拒刀就地反馈兑现**：体内起刀后，刀口处白色刮痕 + 刀口旁 12px 小字「只能从外部
  下刀」（`eval-l1-reject`），反馈终于发生在眼睛看着的地方；底部 toast 仍在，双保险。
  切割被正确拒绝（岛数不变）。
- 音效六件套接入且映射正确（切割 snip/缆线 twang/泄压 hiss/脆断 crack/达标 chime/
  拒刀 thud），同批事件按音色去重。**但无头环境听不到，只按"存在且触发正确"给一半信用。**
- 跟手依旧：慢拖全程无迟滞；这次 L1 目标一顺利完成（拉到 82 分并保持 3 秒达标，
  上轮只能摸到 74），锚定+更早提示间接救了"读数梯度平"的挫败。
- 蓄力环视觉成立：`eval-l1-pull` 金环随保持进度填充，读得懂。

**哪里出戏**

1. 拒刀小字 12px、0.9 秒即褪，对慢反应玩家仍偏快偏小；刮痕 0.5s 也稍纵即逝。
2. 读数对用力的响应梯度本身没动：L1 拉出 72px 才从 74 涨到 82，中段依旧平。
3. 音效听感未验证（音量配比、hiss 刺耳与否、thud 存在感），不能给全信。

**给 Planner 的建议**

1. 拒刀小字加到 14px、驻留 1.5s，刮痕加一次 2px 的抖动衰减——成本三个常数。
2. 读数梯度：在 similarity 输出层对 60–90 区间做一次温和的 gamma 拉伸（纯显示层，
   不动判定），让"方向对了"在中段就有读数反馈。

## 4. 引导清晰度 — 7.5 / 10（+1）

**看到了什么**

- **软锁毒点拔掉了**：目标一期间切断环管，拓扑破坏持续 5 秒后准时弹出
  「管路拓扑已不可恢复，本目标无法达成——按 R 重开试件」，且 hint 栏常驻同文
  （`eval-l2-softlock`，toast+侧栏双处可见）——错过 toast 也不会干耗到超时。
- **越线教学在恰当时机出现**：读数首次过线瞬间 toast「读数越线了——保持住 3 秒！」
  （`eval-l1-holdring`），配合蓄力环，保持机制一次讲透。
- L2 首提示提前到 20 秒，乱按真空期缩短一半。
- 引导链路其余部分照旧完整（intro→目标虚影→渐进提示→双条+达标线→拓扑警告）。

**哪里出戏**

1. **L6 开局依旧一盆冷水**：读数 4 + ⚠管道结构不符，无一字解释（`eval-l6-3d`）。
   上轮已提，本轮计划未排——但对玩家它是每次进 L6 都会撞上的墙。
2. 软锁提示的 toast 只出一次 6 秒；hint 栏虽常驻，但视觉权重低，慢玩家可能仍要
   十几秒才注意到侧栏文字变了。
3. 拒刀小字（同手感节）对第一次犯错的玩家偏易错过。

**给 Planner 的建议**

1. L6 的 intro 或 hint 直接把话说破：「斜撑没断之前，这个读数上不去是正常的」——
   一行文案，冷水变引导。
2. 软锁触发时把侧栏 hint 文字闪烁高亮 1 秒（或топо警告行变红加粗），把视线引过去。

## 5. 惊喜时刻 — 7 / 10（+1.5）

**看到了什么**

- **泄压现在是真事件**：`eval-l2-cut02` 同一帧里——切口处一撮灰白气流粒子外喷、
  膜面正在垮（0.2s 时半塌）、环管开始散链、toast「嘶——」、读数跳水中（49）；
  1 秒后 `eval-l2-cut1s` 塌陷完成、褶皱与降饱和到位。配上 hiss（源码确认触发），
  上轮的"哑剧"变成了有声有形有过程的高光。这是本轮最大的进步。
- 蓄力环从 0 到满的 3 秒 + chime 达标，给了 L1 一个小小的仪式感终点。

**哪里出戏**

1. **粒子气势打了八折**：12–18 粒、0.7 秒即逝，截图里是一小撮灰点。真实的泄压
   应该沿切口持续喷 0.3–0.5 秒、有方向锥、粒子拖尾——现在更像"弹了点灰"。
2. 褶皱没有从切口向外扩散的方向性，塌陷是均匀的，少了"气从这里跑掉"的叙事。
3. **第二个 wow 仍然缺席**：缆线剪断只有 twang 音效接线，端点回甩视觉没做，
   L3/L5 的高光仍是期票；L6 斜撑剪断依旧平淡。

**给 Planner 的建议**

1. 泄压粒子加量加时：沿切口线段连续发射 0.4s（每帧 2–3 粒）、初速沿外法向锥形、
   加 2px 拖尾线——效果层已有骨架，只是参数与发射器形状的事。
2. 缆线剪断回甩：断点两侧各取 3–4 个管路粒子给一次沿切线的冲量 + 0.3s 内画摆动
   残影，配合已有 twang——L3 第二个 wow 即成。
